# 0036 — Guided setup, translated UI and shared video defaults

## Context

Accounts and Voice both exposed credentials, General mixed app and video preferences, and creation dialogs repeated the same voice and layout choices. First launch only chose a mode. Settings changed position when tabs differed in height, and theme transitions briefly hid native dialogs.

## Decision

- First launch (revised by [[0044-full-window-onboarding]]) guides the user through interface language, Learn/Create/Both, agent, sign-in or API key, and narration. Explain subscription versus API billing and ElevenLabs versus local OmniVoice. ElevenLabs is recommended for natural speech and exact timings. Users can explicitly postpone account or voice setup.
- Ship the national languages of European countries, including the transcontinental countries (the exact supported set and native names live in `src/shared/ui-languages.ts`). English remains the source language for code, comments, docs, catalog keys, and project instructions. Store complete offline JSON catalogs in `src/shared/locales/`, shared by the renderer and notifications. The macOS menu bar and its custom commands stay in English regardless of the interface language; account and model controls live in Settings instead of a provider-specific top-level menu. New catalogs are machine-generated drafts: Google for supported languages, supplemented by a temporary local MADLAD translation tool for remaining messages and Romansh; existing Croatian copy is retained. Generation is a developer operation with explicit permission to transfer English interface strings; the shipped app never contacts a translation service. Catalog validation checks completeness, interpolation tokens, and protected product names. A searchable picker, shared by onboarding and Settings, shows native names plus localized names, matches names and language codes without requiring accents, and supports keyboard selection. It stays available on every onboarding step. New installs start with the supported system language, falling back to English; saved choices keep their value. Before the narration step, onboarding language seeds narration only when that language is already offered by the narration picker; otherwise it keeps the current narration choice (English on a new install). Interface-language availability does not imply voice-provider support. At the narration step and afterwards, interface-language changes leave the chosen voice alone; General language changes also leave narration alone. Never translate user content, scene source, mathematical narration or attached material through the UI catalog.
- General owns app language, mode, appearance and folders, with version and update controls last. Show the releases-page fallback only after update failure.
- Agent selects the agent and model. In Settings, provider choices are disabled until Accounts reports a signed-in account or a saved API key in the selected auth mode. Keyboard navigation skips disabled choices and selecting a provider rechecks its status. First-run onboarding still chooses the provider before its sign-in step. Accounts owns every provider credential and desktop-assistant connection. Keys are entered in a focused modal and retain existing OS-encrypted storage and validation. Choosing ElevenLabs without a key directs users to Accounts before it can be used.
- Voice owns provider, narration language directly below the provider choice, and tone. Existing projects can override the new-project defaults. Environment owns component installation, including faster-whisper for exact recording bookmarks.
- Video owns export quality, aspect ratio and the default video theme in Learn and Create. Settings omit the default background type/colour controls and the open video's theme/background controls. Existing saved themes and custom or picture backgrounds remain readable for compatibility; exports can still choose theme versions ([[0013-export-versions-and-languages]]). Scripting is always part of generation ([[0016-script-first]]), rather than a preference. Create additionally exposes preview quality, render-on-save, GPU encoding and render servers, with a guided pairing dialog. Both follows the active Home workspace for these extra controls.
- Creation forms inherit the defaults rather than repeating language, tone, theme, format or narration controls. Existing videos keep their aspect ratio, because layout depends on it ([[0010-fixed-aspect-per-project]]).
- Both libraries use a small plus button, with a larger central plus when empty. A chooser offers quick video, course/series and exercises, plus an editable project and open-folder action in Create.
- Shared segmented controls animate their selection, respecting reduced motion. Settings keep a fixed width and top position; only the body extends downwards and scrolls. Modal dismissal retains the complete content while fading. Theme changes apply directly while a native dialog is open.

## Consequences

This revises the UI-language portion of [[0011-open-source-english]], the control placement in [[0015-tone-and-pacing]], first-launch setup in [[0029-learn-and-create]], and export-quality placement in [[0035-720p-study-videos]]. A project snapshots defaults when created; changing defaults does not rewrite existing projects.
